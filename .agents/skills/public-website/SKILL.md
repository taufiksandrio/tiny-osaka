# Public Website

1. Read docs/REQUIREMENTS.md, docs/CONTENT_AND_UX.md and docs/DATA_CONTRACTS.md.

3. Indonesian only, no language prefix and no hreflang; appropriate meta; no unverified claims, never implement Restaurant schema.
